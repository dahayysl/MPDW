1. Proses MA(2)

Proses MA(2) didefinisikan sebagai:

\[Y_t = e_t + \theta_1 e_{t-1} + \theta_2 e_{t-2}, \quad \theta_1 = 0.4,\ \theta_2 = 0.6\]

dengan \(e_t\) adalah white noise. Karena \(Y_t\) hanya bergantung pada dua nilai error sebelumnya, secara teori proses MA(2) memiliki fungsi autokorelasi (ACF) yang terputus setelah lag ke-2, fungsi autokorelasi parsial (PACF) yang meluruh secara bertahap (tailing off), dan bersifat stasioner untuk sembarang nilai koefisien, karena tidak memiliki syarat kestasioneran seperti pada komponen AR.

Pembangkitan data

theta1 <- 0.4
theta2 <- 0.6

## Manual
ma2_manual <- wn[1:2]
for (i in 3:n) {
  ma2_manual[i] <- wn[i] + theta1 * wn[i - 1] + theta2 * wn[i - 2]
}
ma2_manual <- ts(ma2_manual)

## arima.sim
set.seed(1234)
ma2_sim <- arima.sim(list(order = c(0, 0, 2), ma = c(theta1, theta2)), n = n)

Plot time series

par(mfrow = c(1, 2))
ts.plot(ma2_manual, main = "MA(2) Manual")
ts.plot(ma2_sim, main = "MA(2) arima.sim")

Interpretasi: kedua deret berfluktuasi di sekitar rata-rata konstan (mendekati nol) dengan ragam yang relatif stabil sepanjang waktu, tanpa tren maupun pola musiman. Hal ini merupakan indikasi awal bahwa proses bersifat stasioner, dan hasil pembangkitan manual maupun arima.sim menunjukkan pola yang serupa.

ACF, PACF, dan EACF

par(mfrow = c(1, 2))

acf(ma2_sim, main = "ACF MA(2) arima.sim")

Interpretasi: ACF signifikan pada lag 1 dan lag 2, kemudian terputus menuju nol pada lag ke-3 dan seterusnya.

par(mfrow = c(1, 2))

2. Proses AR(2)

Proses AR(2) didefinisikan sebagai:

\[Y_t = \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + e_t, \quad \phi_1 = 0.5,\ \phi_2 = 0.2\]

Secara teori, proses AR(2) memiliki ACF yang tailing off, PACF yang cut off setelah lag ke-2, dan memerlukan syarat kestasioneran tertentu pada koefisien AR-nya.

Pembangkitan data

phi1 <- 0.5
phi2 <- 0.2

## Manual
set.seed(1234)
ar2_manual <- wn[1:2]
for (i in 3:n) {
  ar2_manual[i] <- phi1 * ar2_manual[i - 1] + phi2 * ar2_manual[i - 2] + wn[i]
}
ar2_manual <- ts(ar2_manual)

## arima.sim
set.seed(1234)
ar2_sim <- arima.sim(list(order = c(2, 0, 0), ar = c(phi1, phi2)), n = n)

Plot time series

par(mfrow = c(1, 2))
ts.plot(ar2_manual, main = "AR(2) Manual")
ts.plot(ar2_sim, main = "AR(2) arima.sim")

Interpretasi: kedua deret berfluktuasi di sekitar rata-rata konstan dengan ragam yang relatif stabil, tanpa tren jangka panjang. Secara visual, proses menunjukkan ciri-ciri stasioner, yang akan dikonfirmasi lebih lanjut melalui uji syarat kestasioneran pada bagian selanjutnya.

ACF, PACF, dan EACF

par(mfrow = c(1, 2))
acf(ar2_manual, main = "ACF AR(2) Manual")
acf(ar2_sim, main = "ACF AR(2) arima.sim")

Interpretasi: ACF meluruh secara bertahap dan tidak pernah benar-benar terputus ke nol, karena setiap nilai \(Y_t\) membawa pengaruh dari seluruh nilai sebelumnya melalui struktur rekursif AR.

Identifikasi stasioneritas

Syarat kestasioneran AR(2): \(\phi_1+\phi_2<1\), \(\phi_2-\phi_1<1\), dan \(|\phi_2|<1\), yang setara dengan akar-akar polinomial karakteristik berada di luar lingkaran satuan (modulus > 1).

Interpretasi: dengan \(\phi_1=0.5\) dan \(\phi_2=0.2\), diperoleh \(\phi_1+\phi_2=0.7<1\), \(\phi_2-\phi_1=-0.3<1\), dan \(|\phi_2|=0.2<1\), sehingga ketiga syarat terpenuhi. Modulus akar polinomial karakteristik yang diperoleh (±1.31 dan ±3.81) juga berada di luar lingkaran satuan. Dengan demikian, proses AR(2) yang dibangkitkan bersifat stasioner.

3. Proses ARMA(2,2)

Proses ARMA(2,2) merupakan gabungan komponen AR(2) dan MA(2):

\[Y_t = \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + e_t + \theta_1 e_{t-1} + \theta_2 e_{t-2}\]

dengan \(\phi_1=0.5\), \(\phi_2=0.2\), \(\theta_1=0.4\), dan \(\theta_2=0.6\). Secara teori, ACF dan PACF proses ARMA campuran sama-sama meluruh secara bertahap (tailing off) tanpa titik cut off yang tegas, dan kestasioneran proses hanya ditentukan oleh komponen AR-nya.

Pembangkitan data

## Manual
set.seed(1234)
arma22_manual <- wn[1:2]
for (i in 3:n) {
  arma22_manual[i] <- phi1 * arma22_manual[i - 1] + phi2 * arma22_manual[i - 2] +
    wn[i] + theta1 * wn[i - 1] + theta2 * wn[i - 2]
}
arma22_manual <- ts(arma22_manual)

## arima.sim
set.seed(1234)
arma22_sim <- arima.sim(list(order = c(2, 0, 2),
                              ar = c(phi1, phi2),
                              ma = c(theta1, theta2)), n = n)

Plot time series

par(mfrow = c(1, 2))
ts.plot(arma22_manual, main = "ARMA(2,2) Manual")
ts.plot(arma22_sim, main = "ARMA(2,2) arima.sim")

Interpretasi: deret berfluktuasi di sekitar rata-rata konstan dengan ragam yang relatif stabil, namun tampak lebih halus (fluktuasi lebih persisten) dibandingkan AR(2) maupun MA(2) secara terpisah, karena adanya pengaruh gabungan dari kedua komponen tersebut.

Dengan demikian, proses ARMA(2,2) yang dibangkitkan bersifat stasioner.
